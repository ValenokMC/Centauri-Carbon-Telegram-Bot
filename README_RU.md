## Зачем это

Печать идёт часами, и знать хочется ровно две вещи: идёт ли она ещё и не
случилось ли чего. Стоять над принтером — не вариант, открывать веб-интерфейс
каждые двадцать минут — тоже.

Обычно такие задачи решают, выставив принтер в интернет или заведя аккаунт в
чьём-то облаке. Здесь ни того, ни другого. Бот работает на компьютере, который у
тебя уже есть, ходит к принтеру по собственной локальной сети и пишет тебе в
Telegram. Токен, chat_id и адрес принтера не покидают твою машину.

- **Одно сообщение, а не поток.** Статус правится на месте. Кнопки правят его
  же. Чат не забивается сотней почти одинаковых сообщений.
- **Пишет тогда, когда это важно.** Старт, пауза, продолжение, финиш,
  остановка и обрыв связи — но только если он затянулся.
- **Отличает «закончилась» от «остановили».** Принтер в обоих случаях отдаёт
  один и тот же код; бот смотрит на достигнутый процент.
- **Опасное спрашивает.** Стоп и пауза требуют подтверждения. Запуск печати —
  тоже, вместе с кадром с камеры, чтобы было видно, что стол пуст.
- **Слушается только тебя.** Всё, что приходит из другого чата, отклоняется.

## Быстрый старт

1. **Получи токен.** Открой [@BotFather](https://t.me/BotFather) в Telegram,
   отправь `/newbot`, ответь на вопросы, скопируй выданный токен.
2. **Скачай и распакуй** [архив для Windows](https://github.com/ValenokMC/Centauri-Carbon-Telegram-Bot/releases/latest).
3. **Запусти `Настроить.cmd`.** Мастер проверит Python, примет токен (не
   показывая его), спросит адрес принтера, проверит связь и отдельно предложит
   добровольную анонимную статистику. Отказ ни на что не влияет.
4. **Нажми `/start`** в своём боте, когда мастер попросит. chat_id он определит
   сам — сторонние боты «узнай свой id» не нужны.
5. **Запусти `Запустить.cmd`.** Отправь боту `/status`.

Вся настройка. Python-файлы открывать не нужно, chat_id вручную вводить не нужно.

По желанию: `Install-Autostart.cmd` поднимает бот при входе в Windows. Перед
созданием задачи он показывает, что именно создаст, и спрашивает;
`Remove-Autostart.cmd` удаляет её.

Подробно: **[docs/installation.md](docs/installation.md)**

### Конфиденциальность

Анонимная статистика по умолчанию выключена. Если человек явно согласился, не
чаще раза в 30 дней передаются только случайный id установки, версия приложения
и код проекта. Telegram-токен и id, IP принтера, файлы, состояние печати и кадры
не передаются. Отказавшийся получает полностью тот же работающий бот. Согласие
можно отозвать повторным запуском `Настроить.cmd`. Подробно: [PRIVACY.md](PRIVACY.md).

## Что умеет

**Наблюдение**

- Состояние: статус, файл, прогресс, слой, остаток времени, сопло и стол
- Кадр с камеры вместе со статусом и `/snap` по требованию
- Краткий и подробный режим — температура камеры, вентиляторы, свет, координаты
- Уведомления: началась · пауза · продолжилась · закончилась · остановлена ·
  связь потеряна · связь восстановлена
- Отчёты о прогрессе каждые *N* процентов, если включить
- Напоминание о смазке направляющих — по реально напечатанным часам

**Управление** *(по желанию — мастер предлагает режим «только мониторинг»)*

- Пауза · продолжить · стоп
- В COSMOS — убрать одну испорченную модель, не останавливая остальные объекты
- Подсветка, и автоматическое выключение ночью после печати
- Скорость печати: 50 / 75 / 100 / 125 / 150 %
- Пресеты нагрева сопла и стола
- Все три вентилятора — набираются черновиком и уходят одной командой
- Список файлов на принтере и запуск печати

Полный список выше относится к штатному SDCP. В COSMOS пауза/продолжение/отмена
и исключение отдельной модели объединены настройкой управления заданием;
удалённый запуск файла включается отдельно. Нагрев, вентиляторы, свет,
скорость, макросы и произвольный G-code остаются недоступными, пока для них нет
проверенного соответствия конкретной установке.

## Совместимость

| | Статус |
|---|---|
| Elegoo Centauri Carbon (1-е поколение), прошивка **V1.4.49** | ✅ Проверено |
| Elegoo Centauri Carbon (1-е поколение), **OpenCentauri/COSMOS** | 🧪 Backend Moonraker покрыт автотестами; проверка на принтере ещё впереди |
| Другие прошивки Centauri Carbon | ⚠️ Скорее всего работает, не проверялось |
| **Elegoo Centauri Carbon 2** | ❌ **Не поддерживается** — другой протокол |
| Любой другой принтер | ❌ Не поддерживается, не проверялось |
| Windows 10 / 11 | ✅ Проверено |
| macOS, Linux | ⚠️ Python-код переносим, launcher'ы и автозапуск — нет |

**Протоколы:** штатная прошивка использует SDCP 3.0.0 по WebSocket на порту 3030
и MJPEG на 3031. COSMOS использует документированный HTTP API Moonraker. Коды
штатных команд взяты из веб-интерфейса принтера, а не угаданы.

**Язык интерфейса:** русский. Код, документация и шаблоны issue — английские.
Полная английская локализация не написана и не проверена, а наполовину
переведённый интерфейс хуже честного одноязычного.

## Безопасность

> [!WARNING]
> **Не пробрасывай порты принтера в интернет.** В SDCP нет никакой
> аутентификации. Кто угодно, кто дотянется до порта 3030, сможет двигать твой
> принтер. Бот рассчитан на локальную сеть и ни на что другое.

- **Одновременно только один экземпляр.** Telegram допускает ровно одного
  потребителя long polling на токен; второй молча забирает апдейты у первого.
- **Слушается только настроенный чат.** Остальное отклоняется.
- **Токен не попадает в лог.** Строки лога чистятся на выходе, поэтому лог можно
  безопасно приложить к issue. `config.json` — нельзя, его не прикладывай.
- **Данные лежат вне папки программы** — в
  `%LOCALAPPDATA%\CentauriCarbonTelegramBot\`, поэтому переустановка или
  распаковка архива поверх ничего не затрёт.
- **Печать, запущенная удалённо, — это всё равно печать.** Ты приказываешь
  горячей машине работать без присмотра. Посмотри на кадр, который покажет бот.

Подробнее: [docs/security.md](docs/security.md) · [SECURITY.md](SECURITY.md)

## Как устроено

```
   Telegram  ⇄  бот (ПК/сервер)  ⇄  принтер (твоя сеть)
             long polling          штатная: SDCP WebSocket + MJPEG
                                   COSMOS: Moonraker HTTP + камера
```

Четыре потока. Один держит WebSocket принтера и превращает статусы в события;
второй не даёт соединению заснуть; третий подновляет сообщение, пока идёт
печать; четвёртый опрашивает Telegram. Всё пользовательское — несколько
маленьких JSON-файлов в `%LOCALAPPDATA%`, записываемых атомарно.

Подробно: [docs/architecture.md](docs/architecture.md)

## Если что-то не работает

| Симптом | Скорее всего |
|---|---|
| `Python not found` | Python не установлен или не в PATH. Переустанови с галочкой *Add python.exe to PATH*. |
| Мастер не находит chat_id | Ты ещё не нажал `/start` в своём боте, либо токен от другого бота. |
| Порт 3030 закрыт | Принтер выключен, в другой сети, или адрес неверный. Посмотри на принтере: Настройки → Сеть. |
| Порт 3031 закрыт | Камера отключена. Всё остальное работает, но без фотографий. |
| Кнопки не отвечают | Запущена вторая копия бота, она забирает апдейты. |
| Два сообщения со статусом | Так бывало в старых версиях. Удали оба — бот создаст новое. |

Полное руководство: [docs/troubleshooting.md](docs/troubleshooting.md)

## Разработка

```bash
git clone https://github.com/ValenokMC/Centauri-Carbon-Telegram-Bot.git
cd Centauri-Carbon-Telegram-Bot
python -m pip install -r requirements-dev.txt
python -m pytest tests/ -q
python tools/check_public_safety.py
```

Тесты не открывают сокетов, не ходят в Telegram и не пишут в настоящий
`%LOCALAPPDATA%` — на каждое из этих утверждений есть отдельный тест.

`tools/check_public_safety.py` не пропускает ничего с личными данными. Запускай
перед pull request; в CI он тоже выполняется.

См. [CONTRIBUTING.md](CONTRIBUTING.md) и [docs/architecture.md](docs/architecture.md).
